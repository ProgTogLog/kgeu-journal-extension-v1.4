Журнал преподавателя КГЭУ — установка

1. Распакуйте ZIP в постоянную папку, например Документы\Журнал КГЭУ.
2. В Chrome откройте chrome://extensions.
3. Включите «Режим разработчика» справа сверху.
4. Нажмите «Загрузить распакованное расширение».
5. Выберите распакованную папку kgeu-journal-extension.
6. Нажмите иконку расширений Chrome и откройте «Журнал преподавателя КГЭУ».

Обновление с версии 1.0.0 / 1.1.0:

1. Распакуйте новый ZIP поверх старой папки расширения.
2. На chrome://extensions нажмите круглую кнопку «Обновить» на карточке расширения.
3. Закройте вкладку журнала и откройте её снова. Не удаляйте расширение: так сохранятся уже внесённые данные.

Начиная с версии 1.4.0 ведомость, список студентов и посещаемость выгружаются в формате Excel (.xlsx). Две лабораторные пары в один день объединяются в одну запись ЛР: например, 18:20–21:30. Для неё ставятся одна посещаемость и один набор баллов. При повторном импорте обновляются только ещё не начавшиеся пары выбранной недели; прошедшие пары и посещаемость не изменяются.

Как импортировать расписание:

1. На вкладке «Студенты» назовите каждую группу точно как в расписании КГЭУ: например, ТРП-1-25.
2. Вставьте список студентов этой группы.
3. Нажмите «Импорт КГЭУ».
4. ID преподавателя по умолчанию — 963 (Кудрявцев Данил Сергеевич). Выберите понедельник нужной недели.
5. Расширение добавит только лабораторные и практические по дисциплине «Базы данных».

При первой импортированной паре для каждой лабораторной или практической срок сдачи назначается через 14 дней. Каждая следующая импортированная пара того же вида привязывается к следующей ещё не выданной работе. Если расписание изменили, вручную отредактируйте пару или работу в журнале.

Данные журнала остаются в браузере. После заметных изменений скачивайте резервную копию JSON.
